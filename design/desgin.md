你是一名资深的儿童产品 UI/UX 设计师、品牌设计师和移动端产品设计师。

请为一款「AI Character Phone / AI 儿童角色电话」微信小程序设计一套完整、高保真、可落地的移动端 UI Design System。

产品核心概念：

这是一个专门为儿童设计的 AI 角色电话生态。

孩子拥有一个实体儿童电话设备，可以通过设备与自己喜欢的 AI 角色进行语音通话。

家长通过微信小程序完成：

* 查看 AI 角色
* 选择角色
* 与角色互动
* 设置角色定时来电
* 查看角色记忆
* 查看孩子与角色的互动
* 绑定实体电话
* 配置设备 Wi-Fi
* 管理设备
* 查看使用情况
* 管理账号和订阅

产品不是传统的儿童教育 App，也不是普通 AI Chat App。

核心体验应该让家长觉得：
「这是一个安全、有趣、有陪伴感的儿童角色世界。」

让孩子觉得：
「这里住着我喜欢的角色，他们真的会给我打电话。」

---

## 一、整体视觉方向

整体视觉风格：

Pastel Cartoon + Soft 3D Character + Storybook UI

关键词：

* 温暖
* 可爱
* 陪伴
* 童话
* 轻松
* 柔软
* 高品质
* 家长认可
* 儿童喜欢
* 有品牌感
* 有轻微梦幻感

不要做成：

* 廉价儿童教育 App
* 传统幼儿园风格
* 过度鲜艳的彩虹色
* 游戏充值 UI
* 传统 AI 科技风
* 赛博朋克
* Glassmorphism
* 过度复杂的渐变
* 成人 SaaS Dashboard
* 过度卡通化导致家长觉得幼稚

整体感觉应该接近：

「一本可以互动的儿童绘本 + 一个现代高品质家庭 App」。

### 我建议你下一步直接按这个结构做 Figma

现在这套产品其实已经可以收敛成 **6 个一级模块、约 25 个核心页面**：

**首页**
→ Banner / 我的角色 / 定时来电 / 设备状态

**角色**
→ 角色列表 / 角色详情 / 角色记忆 / 今日任务 / 故事

**定时**
→ 定时列表 / 选择角色 / 设置时间 / 确认 / 成功

**设备**
→ 未连接 / 配网入口 / 配网步骤 / 配网失败 / 设备管理

**通话**
→ 来电 / 通话中 / 通话结束 / 通话记录

**我的**
→ 家长中心 / 订阅 / 角色包 / 通知 / 设置

这里有个很关键的产品设计点：**「定时来电」应该成为这套产品的第一核心功能，而不是一个普通设置项。** 因为“AI 会主动给孩子打电话”才是这个硬件区别于普通 AI 玩具/AI Chat App 的记忆点。

另外，首页 Banner 我建议从第一天就按照**运营位**设计，而不是写死。以后可以直接做「新角色上线 / 周末冒险 / 节日活动 / 新故事 / 新 IP」等运营内容，不需要改客户端。

如果你接下来准备让 **Claude Code / Codex 直接把这个小程序做出来**，我还可以继续把这份设计稿进一步拆成 **「页面 ID → Frame 尺寸 → 每个组件坐标/尺寸 → 字号 → 颜色 → 圆角 → 文案 → 交互 → API 数据结构」的前端实施级 UI Spec**，基本可以直接拿去开发。
